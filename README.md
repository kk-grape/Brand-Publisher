# 品牌公众号排版器

一个面向品牌公众号运营人员的前端排版工具。用户可以粘贴普通文字或 Markdown，使用规则识别文章结构，并生成 NVIDIA 品牌风格的微信公众号文章预览。

## 核心功能

- Markdown 文章结构识别：标题、段落、引用、有序/无序列表、加粗重点
- NVIDIA 官方模板和手机/电脑预览
- 标题层级、长段落、引用、列表与重点信息的动态质量检查
- 同时写入 `text/html` 和 `text/plain` 的公众号富文本复制
- 导出包含内联样式的 HTML 文件或文章主体 PNG
- 示例文章、完整重置、操作 Toast 和本地自动保存
- 桌面双栏与小屏上下布局

## 技术栈

- Vue 3 + TypeScript + Vite
- Composition API
- markdown-it
- DOMPurify
- lucide-vue-next
- html-to-image
- 原生 CSS

## 项目目录

```text
src/
  components/       页面与交互组件
  data/             演示文章
  templates/        NVIDIA 模板与主题
  types/            文章和质量检查类型
  utils/            解析、检查、复制和导出逻辑
  App.vue            状态编排与自动保存
  main.ts            应用入口
  styles.css         全局视觉与响应式样式
```

## 安装和运行

```bash
npm install
npm run dev
```

Vite 会在终端中显示本地访问地址，通常为 `http://localhost:5173`。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## 公众号复制原理

排版结果通过统一的序列化器生成只使用内联 `style` 的 HTML，并在写入剪贴板前由 DOMPurify 过滤。支持现代 Clipboard API 时，通过 `ClipboardItem` 同时写入 `text/html` 和 `text/plain`；不支持时，使用临时可编辑容器和浏览器复制命令降级。这样粘贴到微信公众号编辑器时，不依赖项目中的 CSS 类，也能尽可能保留字号、颜色、行高、间距、引用框和品牌色。

## 当前版本的不足

- 当前只提供 NVIDIA 官方模板，没有模板编辑器
- 品牌、发布时间和地点暂不支持手动配置
- “AI”分析为浏览器端规则，不理解复杂语义
- 富文本粘贴的最终效果仍可能受目标公众号编辑器的二次清理影响
- 没有后端、协作、云同步和账号系统
- 当前环境未预装 Playwright 浏览器，因此没有自动截图脚本；可以通过“示例文章 → 一键智能排版”手动完成演示

## 后续方向

## AI 在开发过程中的使用

AI 用于需求拆解、组件结构设计、规则设计、代码实现和构建问题排查。产品运行时不调用大模型：当前结构识别主要由 Markdown 和确定性规则完成，产品中标注的“AI”能力是 MVP 规则版本。后续可在保持现有解析与模板接口的基础上接入大模型，增强语义识别、重点提炼和段落改写。
