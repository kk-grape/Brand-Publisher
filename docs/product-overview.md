# 产品说明

## 这是什么项目

品牌公众号排版器是一款面向品牌内容运营人员的前端排版工具。用户将普通文章或 Markdown 粘贴到编辑区，选择识别方式后，系统会整理文章结构，并套用 NVIDIA 品牌视觉生成微信公众号文章预览。

它解决的核心问题不是“替用户写文章”，而是把已经写好的内容快速转换成结构清晰、风格统一、可以复制到微信公众号编辑器的富文本文章。

## 目标用户

- 负责微信公众号文章发布的品牌运营人员
- 需要统一品牌视觉的市场与内容团队
- 希望减少手工调整标题、段落、引用和列表时间的编辑人员
- 用于产品、前端或 AI 应用能力展示的面试与演示场景

## 核心流程

```text
输入或粘贴文章
→ 选择 Markdown 识别或 AI 智能排版
→ 转换为统一文章结构
→ 套用 NVIDIA 品牌模板
→ 检查手机/电脑预览与排版质量
→ 复制到公众号或导出 HTML/PNG
```

## 两种识别方式

### Markdown 识别排版

适合已经包含 `#`、`##`、`>`、列表和加粗标记的文章。所有解析都在浏览器本地完成，不发送网络请求，速度快且结果稳定。

### AI 智能排版

适合普通文本、连续长段落或结构不清晰的内容。MiMo 只负责将原文整理为 Markdown，不负责润色、摘要或扩写；随后仍由本地解析器生成统一文章结构。

## 产品价值

- 减少重复的公众号手工排版工作
- 让同一品牌的文章保持稳定视觉规范
- 用统一数据结构连接规则解析、AI 分析、预览、复制和导出
- 在没有后端和大型 UI 框架的情况下完成可运行、可演示的 MVP

## 当前 MVP 范围

当前版本包含文章输入、结构识别、NVIDIA 模板、质量检查、富文本复制、HTML/PNG 导出和本地自动保存。

当前版本不包含登录、数据库、支付、多人协作、模板编辑器、云端文章历史或安全的服务端 AI 代理。AI Key 由浏览器直接读取，因此只适合本机或受控演示。

## 推荐演示流程

1. 点击“示例文章”填充完整内容。
2. 点击“Markdown 识别排版”生成稳定预览。
3. 切换手机和电脑预览。
4. 打开右下角“排版检查”查看动态建议。
5. 点击“复制到公众号”，粘贴到微信公众号编辑器。
6. 展示 HTML 与 PNG 导出。
7. 再粘贴一段普通文本，演示“AI 智能排版”。
