# 使用指南

## 启动项目

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址，通常为 `http://localhost:5173`。MiMo 的本机配置方式见项目根目录的 [README](../README.md)。

## 输入文章

在左侧“原始内容”区域输入或粘贴文章。系统会实时统计字数、小标题、引用和列表要点，并自动保存原文、当前模板和预览模式。

刷新页面后会恢复上一次输入。点击“清空”或顶部“重置”可以移除内容；“重置”还会恢复手机预览模式。

## Markdown 识别排版

当文章已经带有结构标记时，优先使用“Markdown 识别排版”。支持：

```markdown
# 文章主标题

## 二级标题

### 三级标题

普通段落和 **重点文字**。

> 引用内容

- 无序列表
- 无序列表

1. 有序列表
2. 有序列表
```

当前 NVIDIA 模板中，二级标题使用绿色双线样式；三级标题使用黑色小字和绿色描边框。绿色菱形分割线只出现在相邻二级章节之间。

双引号包裹的文字会使用品牌绿色，例如 `“重点信息”` 或 `"重点信息"`。

## AI 智能排版

普通文本可以使用“AI 智能排版”。请求期间按钮显示“AI 正在分析……”，并暂时禁用两个排版入口，避免结果互相覆盖。

AI 返回 Markdown 后，本地仍会调用与 Markdown 模式相同的解析器和 NVIDIA 模板。AI 失败时：

- 左侧原文不会被清空
- 上一次成功预览不会被覆盖
- 页面显示明确错误和“重新尝试”入口
- 可以立即改用 Markdown 识别

当前 MVP 会检查 AI 是否返回受支持的 Markdown，并拒绝 HTML、链接、图片和代码块。严格原文保真比较已经保留在代码中，但暂未接入主流程。

## 查看预览

- “手机预览”使用约 420px 的文章宽度。
- “电脑预览”放大文章展示区域。
- 右下角“排版检查”默认收起，点击后显示检查面板。
- 检查面板可以拖动、关闭；再次点击入口时会回到默认位置。

质量检查会关注主标题、标题数量与层级、长段落、连续长段落、引用、列表和重点信息。

## 复制和导出

完成排版后点击“复制到公众号”。剪贴板会同时写入：

- `text/html`：带内联样式的公众号兼容富文本
- `text/plain`：不带装饰的纯文本备用内容

顶部“导出”菜单提供：

- 导出 HTML 文件：生成可以独立打开的完整文章
- 导出预览 PNG：只截取文章主体，不包含应用界面和质量面板

## 常见问题

### 粘贴后和预览不完全相同

微信公众号会二次清理粘贴的 HTML，而且不同微信版本、系统字体和编辑器宽度会影响换行。当前模板已经使用兼容标签、内联样式和真实装饰字符缩小差异，但不能保证像素级一致。

### AI 提示网络或鉴权错误

检查 `.env.local` 中的 Provider、API Key、Base URL 和模型名称，然后重新启动开发服务器。浏览器直连还会受到网络、额度和接口权限影响。

### 复制按钮不可用

必须先通过 Markdown 或 AI 成功生成预览。浏览器还需要允许页面访问剪贴板，建议使用最新版 Chrome 或 Edge。

### 没有识别到主标题

Markdown 模式需要使用 `# 标题`。AI 模式不会凭空生成原文中不存在的标题；没有主标题时，预览会省略标题区域，并由质量检查给出提示。
