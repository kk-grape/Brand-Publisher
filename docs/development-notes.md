# 开发说明与当前进度

更新日期：2026-08-02

## 当前已完成

- Vue 3、TypeScript、Vite 和 Composition API 项目结构
- NVIDIA 官方模板及模板选择展示入口
- Markdown 标题、段落、引用、列表和加粗解析
- Markdown 与 MiMo AI 两种排版入口
- 手机/电脑预览和响应式双栏布局
- 动态排版质量检查及可拖动、可隐藏面板
- 富文本复制、纯文本备用复制和旧浏览器降级
- HTML 与文章主体 PNG 导出
- 示例文章、重置、Toast 和 localStorage 自动保存
- 公众号兼容 HTML、内联主题和装饰字符
- 主要源码的中文职责与复杂逻辑注释

## 当前排版规则

- `#`：文章主标题，使用黑色粗体和黑绿横条装饰
- `##`：二级章节标题，使用绿色文字和黑绿双下划线
- `###`：三级标题，使用较小黑色文字和绿色描边框
- 绿色菱形分割线只出现在相邻二级章节之间
- 成对中文或英文双引号及其内容使用品牌绿色
- 无序列表使用绿色圆角方形与白色空心圆 Logo
- 有序列表使用绿色数字

## 已确定的技术决策

### 统一 ArticleDocument

Markdown 与 AI 只负责识别结构，所有后续功能共用 `ArticleDocument` 和 NVIDIA 序列化器，不维护第二套模板 HTML。

### AI 只排版，不写作

MiMo 只返回 Markdown，不负责润色、摘要、扩写、补充事实或直接生成 HTML/CSS。AI Markdown 只用于预览，不覆盖左侧原文。

### 原文保真校验暂缓接入

严格可见文字指纹比较已经实现并保留。由于模型把完整句子提升为标题或列表时可能调整标点，MVP 主流程目前只执行 Markdown 语法安全检查。后续应实现差异分级后再恢复阻断。

### 公众号兼容优先

预览、复制和 HTML 导出统一使用保守的内联 HTML。复杂几何装饰改用真实字符，优先保证微信公众号粘贴后的稳定性，而不是追求浏览器中的复杂 CSS 效果。

## 已知限制

- 当前只有 NVIDIA 官方模板，自定义模板只是禁用展示项
- 浏览器端 MiMo Key 无法保密，只适合本机演示
- MiMo 调用仍受网络、额度、权限和接口状态影响
- 公众号会二次清理富文本，不同微信版本无法保证像素级一致
- AI 输出长度受 `max_completion_tokens` 限制，特别长的文章可能失败
- 没有登录、数据库、云同步、文章历史和多人协作
- 目前没有 Playwright 自动化截图与公众号端到端测试

## 建议后续顺序

1. 收集微信公众号真实粘贴截图，继续缩小剩余样式差异。
2. 为 AI 原文保真实现“正文硬错误、结构标点软提示”的差异分级。
3. 增加 AI 长文章截断检测和更明确的错误说明。
4. 将 MiMo 请求迁移到安全的服务端或边缘代理。
5. 增加第二个品牌模板，验证模板注册结构的扩展能力。
6. 增加 Playwright 主流程和视觉回归测试。
